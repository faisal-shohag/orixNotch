# Social media posters

Render: `pwsh marketing/store-shots/Make-StoreShots.ps1` (captures the notch once), then `pwsh marketing/social/Make-SocialPosters.ps1`.
Output: `out/<size>/<poster>.png` (gitignored) — square 1080×1080, portrait 1080×1350, story 1080×1920, landscape 1600×900, all at 2x.
Edit copy in `posters/*.html`, layout in `posters/social.css`. Say "free"; don't call it open source (no license yet).
